# Task

Build a local Python game server that hosts turn-based multiplayer games through
a pluggable per-game logic module, starting with Othello. Multiple players connect
at once, each from their own browser-based HTML client, which provides a game
directory and a view for each game. Version 1 is local-only with no
authentication. The goal is a clean core that new games can be added to without
changing the server.

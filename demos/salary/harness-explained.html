System walkthrough

Payroll math stays certain. AI makes it clear.

This small harness combines a deterministic payroll engine with a LangChain agent. The calculator owns every number; the model only gathers facts, calls trusted tools, and explains the result.

The governing idea
Separate calculation from interpretation.

An LLM is useful for readable summaries and anomaly guidance, but it is not trusted to calculate salary or silently change the official result.

● PayrollResult is ground truth. SlipReview is checked commentary.

02 / Run sequence

What happens for each employee.

The outer loop is ordinary Python. LangChain is a bounded component inside it—not the owner of the complete payroll workflow.

Boot and verify dependencies

The CLI may start the embedded FastAPI server, then checks /health. It also requires an OpenAI key unless --no-llm is set.

Select the run scope

The client lists employees, validates optional --employee filters, creates the month directory, and fetches holidays once.

Calculate the official payroll

For every employee, attendance and holiday data are passed to calculate_payroll. The returned PayrollResult is the reference result.

Ask the agent for a review

The agent receives only an employee ID and month. It must call tools to gather source data and retrieve the official calculation.

Validate, retry, or drop the review

The harness compares the typed answer to ground truth. A rejected answer gets precise feedback and one more attempt; payroll issuance never depends on AI success.

Publish auditable artifacts

Each employee gets an HTML slip and JSON record. The run also writes an index and exits non-zero if any AI review remained invalid.

03 / LangChain

The building blocks inside the agent.

LangChain supplies the model adapter, tool contracts, agent loop, message history, and structured response handling. Business truth remains in the application’s own Python functions.

Model adapter

ChatOpenAI

Connects the agent to the selected OpenAI chat model. Temperature is zero to reduce unnecessary variation.

ChatOpenAI(model=model,
temperature=0)
Tool contracts

@tool

Turns three local functions into callable capabilities, using function signatures and docstrings as the model-facing contract.

get_attendance
calculate_payroll
Agent runtime

create_agent

Combines the model, tools, and system prompt. It manages the tool-call loop until the model can produce its final response.

create_agent(llm, tools,
system_prompt=...)
Typed output

response_format

A Pydantic SlipReview schema constrains the final shape: IDs, amounts, summary, anomaly notes, and HR flag.

Conversation state

HumanMessage

The first message requests a review. On retry, previous messages are preserved and a new message contains exact validation failures.

Final result

The agent state exposes a parsed SlipReview and the full message history, including tool messages used for diagnostics and retry.

05 / Guardrails

Exactly what the harness verifies.

✓

Correct employee and month

The review cannot drift to another person or reporting period.

✓

Exact gross and net pay

Both numbers must match the Decimal calculator to within half a cent.

✓

Required anomaly coverage

Every warning and critical anomaly needs a matching date-and-code note.

✓

No invented anomalies

Every note must map back to an anomaly actually emitted by the calculator.

✓

Consistent HR escalation

The HR flag is true if and only if a warning or critical issue exists.

✓

Graceful model failure

Network, parsing, and model errors remove the optional review—not the salary slip.

06 / Source map

Where each responsibility lives.

harness.py

CLI orchestration, employee loop, validation, retry policy, output writing, and process exit status.

payroll/agent.py

LangChain tools, system prompt, OpenAI model adapter, structured schema, and agent invocation.

payroll/calculator.py

All deterministic money rules, overtime, leave, tax, deductions, and anomaly detection.

payroll/client.py

Typed access to employee, attendance, holiday, and health endpoints in the Hilanet API.

payroll/models.py

Pydantic domain contracts shared between the API client, calculator, harness, and renderer.

payroll/slip.py

Jinja rendering of official payroll data plus the optional, already validated AI review.

LangChain lets the model use the system; the harness decides whether the model’s account of that system is safe to publish.
